# Placar DV — versões

Aqui ficam só os arquivos prontos para instalar do Placar DV (nome provisório),
um aplicativo acessível para acompanhar o futebol de cegos, o goalball e o judô
paralímpico. O código não fica neste repositório.

O aplicativo se atualiza sozinho a partir das versões publicadas aqui.

Este aplicativo não é oficial e não tem ligação com a CBDV.
